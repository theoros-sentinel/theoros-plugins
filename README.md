# 테오로스 플러그인 (Theoros Plugins)

[테오로스](https://github.com/theoros-sentinel/theoros)의 플러그인을 받는 곳입니다. 서명된 플러그인 파일(`.theoros-plugin`)은 이 리포의 Releases에 있습니다.

**Digital Extremes 및 warframe.market과 관련 없는 비공식 팬 프로그램입니다.** Warframe은 Digital Extremes Ltd.의 상표입니다.

## 플러그인

플러그인은 테오로스 설치 파일에 들어 있지 않습니다. 사용하지 않아도 테오로스는 동작합니다. 설치할 플러그인은 이용자가 고르며, 자동으로 설치하거나 업데이트하지 않습니다.

| 플러그인 | 하는 일 | 접속하는 곳 |
|---|---|---|
| VPN 호스트 필터 | VPN 호스트와 매칭되지 않게 합니다. 국가를 고르면 그 국가의 호스트도 피합니다. | IP 대역 목록 사이트 (`www.ipdeny.com`, `ftp.apnic.net`, `iptoasn.com`) |
| 게임에서 바로 가져오기 | 게임 보관함을 보유 목록으로 가져옵니다. 게임 메모리에서 접속 정보를 읽습니다. | DE 서버 (`mobile.warframe.com`, `api.warframe.com`) |
| 보상 오버레이 | 성유물 추천, 보상 시세·두캇, 리벤 등급·가격, 거래 알림을 오버레이로 보여 줍니다. | 개발자 서버 (`wf.toplo.kr`) |

- 보상 오버레이는 보상 이름을 다 읽지 못한 화면을 개발자 서버에 보냅니다. 처음부터 켜져 있으며, 보상 오버레이 화면에서 "인식에 실패한 화면을 개선용으로 보내기"를 끄면 보내지 않습니다.
- 보내는 정보, PC에 남는 것, 끄는 법은 각 플러그인의 이용 안내에 있습니다. 이용 안내는 설치하기 전에 보여 주고, 설치한 뒤에는 「플러그인」 화면의 "안내"로 다시 볼 수 있습니다.

## 설치

테오로스의 「플러그인」 화면에서 설치합니다.

1. 테오로스 메뉴에서 「플러그인」을 엽니다.
2. 설치할 플러그인을 체크하고 "설치…"를 누릅니다. 고른 플러그인은 이 리포의 Releases에서 내려받습니다.
3. 이용 안내가 나오면 읽고 "설치"를 누릅니다.
4. Windows 승인 창에서 "예"를 누릅니다. 여러 개를 골라도 승인은 한 번입니다.

새로 설치한 플러그인은 다시 시작하지 않아도 바로 켜집니다. 이미 켜져 있는 플러그인을 업데이트하거나 지우면 테오로스가 꺼졌다가 다시 켜집니다.

### 파일로 설치

Releases에서 `.theoros-plugin` 파일을 받아 더블클릭합니다. 파일을 테오로스 창에 끌어다 놓거나, 「플러그인」 화면에서 "파일로 설치…"를 눌러도 됩니다.

## 서명 확인

플러그인 파일은 모두 개발자가 서명했습니다. 테오로스는 이용 안내를 보여 주기 전에 서명과 파일 해시를 확인합니다. 맞지 않는 플러그인은 설치하지 않고 이유를 보여 줍니다. 테오로스를 켤 때마다 다시 확인하고, 서명이 확인된 플러그인만 불러옵니다.

## 제거

「플러그인」 화면에서 "제거"를 누릅니다.

- VPN 호스트 필터를 지울 때는 먼저 그 화면에서 "규칙 제거"를 누르세요. 플러그인을 지워도 방화벽 규칙은 남아 계속 막습니다.
- 이미 지웠다면 「고급 보안이 포함된 Windows Defender 방화벽」(`wf.msc`)의 인바운드·아웃바운드 규칙에서 이름이 `Theoros VPN Host Filter`로 시작하는 규칙을 지우세요.
- 플러그인을 지워도 설정과 자료는 `%LOCALAPPDATA%\Theoros\plugins\` 안의 그 플러그인 폴더에 남습니다. 필요 없으면 그 폴더를 직접 지우세요.

## 계정 제재와 위험

- DE는 외부 프로그램을 쓰는 책임이 이용자 본인에게 있다고 밝히고 있습니다.
- 계정 제재 여부는 DE가 판단합니다. 플러그인을 써도 제재받지 않는다고 보장하지 않습니다.
- 플러그인별 위험은 각 플러그인의 이용 안내에 있습니다.
